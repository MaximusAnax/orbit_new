# Ethos — Scoping review log

Audit trail for the scoping critique loop. Two adversarial reviews were run
against the first draft of SCOPE.md / DATA_MODEL.md / EVALS.md: an
**evaluation** review (16 findings: 4 blockers, 8 majors, 4 minors) and a
**design** review (13 findings: 7 majors, 6 minors). Every finding is listed
below with how it was resolved. Nothing was silently dropped.

Headline outcome: the architecture did not change. What changed is what the
green checkmark means — four load-bearing gates could previously be passed by
an implementation (and a corpus) that was bad at the actual task.

The shared-mode failure is additionally closed at source by the byte-preserving loader contract (FR-1 layer 2, gate C1). Baseline restated honestly as "1.0 by construction; the value is independence, not discrimination"; the ≈0.55 number moved to where it belongs (M4). |

(c) Because a score threshold provably cannot separate those, FR-4 gains a second signal: an **IDF-weighted query-coverage floor κ** (unseen terms carry maximum IDF, so a question built from vocabulary the taxonomy never heard of abstains even when it scores well on generic moral words). ## Scope kept in budget

The rework adds ~650 lines of eval and verifier code. To stay inside the
2–4k-line mandate rather than inflating scope, four features were cut to
non-goals (SCOPE non-goals 5, 6, 13) and the line budget re-derived honestly
to include tests and evals (SCOPE D17, ≈ 3,950 total):

| Cut | Rationale |
|---|---|
| Bookmarks (was FR-12) | History + `ethos show` covers revisiting; ~150 lines across store/API/CLI/models. |
| `POST /questions/{id}/answers` re-compose | A re-ask with different options is one command; the filtered and polish paths are exercised directly by M5 and M4. |
| Ambiguity flag and δ | Finding 6 — unmeasurable without two more gates; top-3 alternates deliver the value. |
| Live embedding router | Could never be evaluated hermetically (already half-excluded by the old non-goal 5); only the `TopicRouter` Protocol remains so it can be added later. |
